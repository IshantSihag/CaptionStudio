What do I need installed?

Caption Studio uses two free tools. They only need to be installed once:

  1. ffmpeg — extracts the audio and burns the captions in
    brew install ffmpeg
  2. whisper-ctranslate2 — turns speech into text
    python3 -m pip install -U whisper-ctranslate2

Then click “Check again” below. (The very first transcription also downloads the “small” speech model, about 460 MB — that only happens once.)
